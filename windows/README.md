# Windows community build 0.6.5

This directory contains the Windows C# / Avalonia application, core engine, CLI, tests,
installer and release tools. See [the repository README](../README.md) for download and build commands,
[CUSTOMIZATION.md](CUSTOMIZATION.md) for changes, and [INSTALLING.md](INSTALLING.md) for use and upgrades.

Features are ported manually from the Mac source; this Windows repository does not compile the Swift app.
Keep the editable `.comp` format and English/Chinese switching. A source comparison alone does not verify
pixel-perfect rendering or native Mac animation timing. Known remaining work is in
[the parity checklist](../docs/mac-parity-checklist.md).
