# Mac 对齐记录

比较对象：Mac 源码 af30c45c10b1cddc2b9fe8401c137f250d50abb6（1.4.7）；社区 Windows 基线 c51be1e57d699edce857115f43bbca579f18dcd4。本记录区分源码移植、Windows 自动检查和实机对照；没有将源码比较标为像素级完成。

0.6.7 已加入图层与文件夹拖动／Ctrl 复制、Alt 蒙版复制、应用内 TTF/OTF 字体导入与持久保存、PNG 三档无损压缩和 JPEG 质量／实际压缩预览。渐变共用圆角边界，工具栏按名称自然宽度排列，名称与首个控件相隔 8 像素，笔刷／橡皮擦同组切换保持稳定；采样笔尖显示缓存透明轮廓，素材通用说明已精简。1032 项核心测试、4043 项界面断言、1025 项新增交互断言及十六组最终 EXE 检查通过；104 个双语弹窗用例、12 轮导出关闭压力检查、三次原生启动和安装／升级／卸载检查通过，已覆盖安装。公开发布与云端验证正在进行，见[阶段 13B](13b-verification-release.md)。字体尚未嵌入工程；蒙版独立变换、跨工程图层拖放、复杂文字整形与 Mac 实机对照仍待完成。

0.6.6 已补齐选区新建／添加／减去及扩展／收缩／羽化、魔棒内联容差与取样大小；文字新增系统字体、大小、颜色、对齐、字距和行距实时调整，以及完成／取消。修复取消文字或颜色时的空撤销与重做丢失、最大取样标题截断，保留 Windows 输入与窗口操作。1011 项核心测试、4496 项界面断言、102 项新增交互检查及十五组最终 EXE 检查通过，已覆盖安装；已公开发布 0.6.6，独立 Windows 云端 1011 项核心测试和十五组最终程序检查通过，发布文件保持不变，见[阶段 12A](12a-selection-type.md)及[交付证据](12b-install-release.md)。选区 AI 对象模式、逐段文字格式、字体悬停预览、复杂文字整形与 Mac 实机对照仍未完成。

0.6.5 已加入当前笔刷样式预览按钮、14 种笔刷、18 种形状、12 组渐变、10 种图案、36 个色板颜色，及 SVG/GGR/图片图案/GPL 素材导入。真实绘制预览、取消还原和图案一次撤销已检查；渐变五种模式底层实现已补齐。进一步修复形状预览拉伸、SVG 样本比例、渐变圆角与透明底色，以及派生下拉框未显示和中文选项问题。样式、窗口尺寸与位置在显示前准备，首帧绘制完成后再呈现原生窗口。1000 项核心测试、3714 个界面断言、102 组双语弹窗、71 项素材与启动断言及十四组最终 EXE 检查通过；三次原生首帧顺序检查通过，已覆盖安装并保留设置，公开 0.6.5 发布及独立 Windows 云端 1000 项核心测试和十四组程序检查通过，见[交付与云端证据](11c-install-release.md)。见[阶段 11A](11a-materials-preview.md)及[阶段 11B](11b-preview-startup.md)。新增可编辑形状使用 Windows 格式 12，普通工程仍为 11，旧 Mac 需 PNG/PSD 导出。首帧顺序检查不等于显示器实拍：原生 Mac 时序、不同物理 DPI 和所有显卡的首帧仍未实机验收。

0.6.4 已加入大小滑条与数字并存、窄窗口折叠轨道，以及直接形状切换；修复形状传递和过期预览缓存。新增 ABR 静态笔尖／PNG 导入（非 Mac 已有导入实现的恢复）。液化与涂抹通过轨迹索引提速，四类工具最终像素与修改前一致。962 项核心测试、十三组最终 EXE 检查通过；已覆盖安装并公开发布，独立 Windows 云端 962 项核心测试和十三组程序检查通过，见[阶段 10b](10b-install-release.md)。完整 ABR 动态参数、逐段实时液化、图章／模糊及复杂合成仍待优化。

0.6.3 已修复同组工具栏文字推移与菜单间隙闪烁；笔刷／橡皮擦按输入增量累计，长笔画预览复用，形状与套索绘制减少重复工作。900 项核心测试、十二组最终 EXE 检查通过；八组最终笔画像素与修改前完全一致。已覆盖安装并公开发布，独立 Windows 云端十二组检查通过，见[0.6.3 交付与扩展性能检查](09b-install-release.md)。补查确认液化／涂抹、图章／模糊笔刷、最终填充和部分滤镜仍有明显计算等待；其中液化／涂抹的计算瓶颈已在 0.6.4 优化，其余仍待处理。

0.6.2 已修复左侧工具、分段和标签的悬停／按下背景叠色，标签文字改为复用，避免悬停状态短暂丢失。24 项新像素与衔接检查、2229 个界面断言、十一组最终程序检查通过，已覆盖安装；已公开发布且独立 Windows 云端构建成功，见[0.6.2 交付报告](08b-install-release.md)。见[单层选择背景报告](08a-selection-surfaces.md)。
