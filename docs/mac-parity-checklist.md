0.6.4 已加入大小滑条与数字并存、窄窗口折叠轨道，以及直接形状切换；修复形状传递和过期预览缓存。新增 ABR 静态笔尖／PNG 导入（非 Mac 已有导入实现的恢复）。液化与涂抹通过轨迹索引提速，四类工具最终像素与修改前一致。962 项核心测试、十三组最终 EXE 检查通过；安装与发布正在进行，见[阶段 10a](10a-brush-tools.md)。完整 ABR 动态参数、逐段实时液化、图章／模糊及复杂合成仍待优化。

0.6.2 已修复左侧工具、分段和标签的悬停／按下背景叠色，标签文字改为复用，避免悬停状态短暂丢失。24 项新像素与衔接检查、2229 个界面断言、十一组最终程序检查通过，已覆盖安装；已公开发布且独立 Windows 云端构建成功，见[0.6.2 交付报告](08b-install-release.md)。见[单层选择背景报告](08a-selection-surfaces.md)。
